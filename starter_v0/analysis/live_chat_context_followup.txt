Agent> **Tóm tắt `st.chat_input` trong Streamlit (theo docs chính thức v1.67.0)**

`st.chat_input` là widget dùng để hiển thị ô nhập tin nhắn trong các ứng dụng chat Streamlit. Dưới đây là các điểm chính:

| Tham số | Mô tả |
|---|---|
| **placeholder** | Văn bản hiển thị khi ô rỗng. Mặc định là `"Your message"`. **Lưu ý:** Không nên để chuỗi rỗng vì lý do truy cậpibilité. |
| **key** | Khóa duy nhất để widget giữ trạng thái qua rerun. Nếu `None` sẽ tự tạo. Đặt key giúp đọc/ghi giá trị qua `st.session_state[key]`. |
| **max_chars** | Giới hạn số ký tự nhập. Mặc định `None` (không giới hạn). |
| **max_upload_size** | Kích thước file tối đa (MB). Mặc định `None` tuân theo cài `server.maxUploadSize` trong `config.toml`. |
| **accept_file** | Cho phép upload file: `False` (mặc định), `True` (một file), `"multiple"`, `"directory"`. |
| **file_type** | Loại file được phép (ext, MIME type, hoặc wildcard như `"image/*"`). |
| **accept_audio** / **audio_sample_rate** | Tích hợp ghi âm audio (mặc định 16000 Hz). |
| **disabled** | Vô hiệu hóa widget. |
| **submit_mode** | Chế độ gửi, mặc định `"submit"`. |
| **on_submit, args, kwargs** | Xử lý khi người dùng gửi. |
| **width, height** | Kích thước widget (`"stretch"` mặc định). |

💡 **Tip:** Đọc hướng dẫn "[Build a basic LLM chat app](https://docs.streamlit.io/develop/tutorials/chat-and-llm-apps/build-conversational-apps)" để biết cách kết hợp `st.chat_message` và `st.chat_input` xây dựng ứng dụng chat hoàn chỉnh.
